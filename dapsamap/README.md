# 답사맵

답사 사진을 넣으면 **답사지별로 자동으로 묶고**, 지도에서 다녀온 건물을 고르면 **그 건물 주변 사진이 모이고**, 그 안에서 **건축요소별로 분류**하고 **찍은 위치와 방향을 바로잡는** 도구입니다.
"데이터 연계 & 프로세스 혁신" 과제(10–15주)의 프로토타입입니다.

## 실행

```bash
npm run dapsamap      # http://localhost:8000
```

설치할 것이 없습니다(Node 18 이상). 라이브러리는 `vendor/`에 들어 있어 인터넷 CDN 없이 열립니다. 지도 타일만 인터넷이 필요합니다.

## 쓰는 순서

1. **사진 넣기**: 폴더째 끌어다 놓거나 버튼으로 고릅니다. 촬영 시각 간격(기본 40분)이나 600m 이상 이동을 기준으로 답사지가 나뉩니다.
2. **답사지 선택**: 왼쪽 목록에서 고르면 그 답사지의 사진 점과 동선만 지도에 보입니다. 이름은 두 번 눌러 바꿉니다.
3. **건물 고르기**: 버튼을 누르고 지도에서 건물을 클릭합니다. 반경(기본 60m) 안의 사진이 모입니다.
   - 브이월드 키가 있으면 그 자리의 **건물 윤곽·층수·주소**를 가져옵니다.
   - 키가 없으면 클릭한 지점을 건물로 씁니다.
4. **요소 분류**: 사진을 고르고 숫자키 `1` `2` `3`… (기본: 입구·시장·아파트). `←` `→`로 다음 사진, `0`으로 지우기.
5. **위치·방향 보정**: "지도에서 위치 옮기기"를 누르고 검은 점을 끕니다. 방향은 슬라이더로 맞춥니다. 원래 GPS 값은 지워지지 않습니다.
6. **빠진 사진 넣기**: 건물을 연 채로 지도의 다른 점을 누르면 그 사진이 이 건물로 들어옵니다.
7. **내보내기**: GeoJSON(건물·촬영 지점) / CSV(엑셀) / JSON 백업.

## 아이폰 사진

- HEIC도 읽습니다(처음 HEIC를 만나면 변환기 1.3MB를 불러옵니다). 많이 넣으면 느리므로 **설정 → 카메라 → 포맷 → 높은 호환성**(JPG)을 권합니다.
- **카카오톡·메신저로 보낸 사진은 위치 정보가 지워집니다.** AirDrop, 케이블, iCloud 원본 다운로드로 옮기세요. AirDrop은 공유 화면의 "옵션 → 모든 사진 데이터"를 켭니다.
- 방향(`GPSImgDirection`)은 아이폰이 대부분 기록합니다. 없으면 슬라이더로 넣습니다.

## 브이월드 연결

1. [vworld.kr](https://www.vworld.kr) → 인증키 발급. 서비스 URL에 `http://localhost:8000`(그리고 배포 주소)을 등록합니다.
2. 답사맵 **설정**에 키를 넣습니다. 배경지도가 브이월드(일반/위성)로 바뀝니다.
3. 건물 윤곽은 데이터 API의 `LT_C_SPBD` 레이어로 요청합니다. 다른 레이어가 맞으면 설정에서 바꿉니다.

> 브이월드 연결부(`vworld.js`)는 아직 실제 키로 확인하지 못했습니다. 키를 받으면 가장 먼저 시험할 부분입니다.

## 데이터

브라우저 IndexedDB에 저장됩니다(이 컴퓨터, 이 브라우저 안). **사진 원본은 저장하지 않고** 긴 변 1600px 미리보기만 둡니다. 백업 JSON에는 미리보기가 빠지므로, 다른 컴퓨터에서 백업을 불러온 뒤 같은 사진을 다시 넣으면 미리보기만 채워집니다.

| 목록 | 무엇 | 누가 고치나 |
|---|---|---|
| `photos` | 파일명, 촬영 시각, GPS, 방향, 카메라 | 아무도(사진에서 읽은 원본) |
| `sites` | 자동으로 묶인 답사지, 이름 | 사람(이름) |
| `buildings` | 고른 건물, 윤곽, 층수, 주소, 브이월드 원본 속성 | 사람 |
| `shots` | 사진 하나의 판단: 건물, 요소, 보정 위치·방향, 메모 | 사람 |

저장소 전체의 [데이터 보존 원칙](../docs/DATA_POLICY.md)을 따릅니다. ID는 바꾸지 않고, 모르는 필드는 지우지 않으며, 건물을 지워도 사진의 요소·메모는 남습니다. 설정에서 요소 이름을 바꿔도 이미 붙인 요소는 그대로 남아 탭에 계속 보입니다.

## 파일

```
index.html   화면 뼈대
style.css    스타일
store.js     IndexedDB 저장
vworld.js    브이월드 지도·주소·건물
photos.js    EXIF 읽기, 미리보기, 답사지 묶기, 거리 계산
app.js       화면과 흐름
serve.mjs    로컬 서버
vendor/      Leaflet 1.9.4, exifr 7.1.3, heic2any 0.0.4 (각 LICENSE 포함)
```
