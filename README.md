# 시장아파트 답사 아카이브

시장과 주거가 하나의 건축물로 결합된 **시장아파트**를 전국 단위로 답사·기록하고, 입지와 형태를 비교 분석하기 위한 연구 도구입니다. 건축학과 논문 연구를 위해 만들어졌습니다.

사진 저장 앱이 아니라 **공간 데이터 아카이브**를 목표로 합니다. 모든 프로젝트는 세 층의 데이터를 함께 갖습니다.

| | |
|---|---|
| **공간 데이터** | 어디에 있는가 — 좌표, 행정구역, 철도역·터미널·시장과의 거리 |
| **건축 데이터** | 어떤 건물인가 — 층수, 시장–주거 결합 방식, 규모, 현재 상태 |
| **관찰 데이터** | 현장에서 무엇을 발견했는가 — 사진, 답사 기록, 연구 메모 |

---

## 빠르게 시작하기

```bash
git clone <이 저장소 주소>
cd market-apartment-archive
npm run dev          # http://localhost:5173
```

설치할 의존성이 없습니다. Node 18 이상이면 바로 돌아갑니다. `src/` 의 파일을 저장하면 다시 빌드되고, 브라우저를 새로고침하면 반영됩니다.

```bash
npm run build        # dist/index.html · dist/preview.html 생성
npm run check        # 문법 검사
npm run geo          # 행정경계 데이터 재생성 (평소에는 실행할 일 없음)
```

## 저장소 구조

```
src/
  index.head.html    <title> · 웹폰트 · 전체 CSS (디자인 토큰, 라이트/다크)
  index.body.html    마크업 — 6개 화면의 뼈대와 아이콘 정의
  data/geo.js        전국 행정경계 (시도 17 · 시군구 249, 약 160KB)
  core.js            상수 · 저장소 백엔드 · 마이그레이션 · 부팅 · 화면 전환
  map.js             지도 엔진 — 투영, 팬/줌, 마커, 레이어, 좌표→행정구역 판별
  projects.js        프로젝트 표 · 상세 화면 · 사진 · 답사 기록
  elevation.js       입면 원근 보정 · 선 추출 · PNG/SVG/DXF 내보내기
  analysis.js        분석 · AI 질의 · 보고서/슬라이드 · 설정   ← 마지막 줄에서 boot()
scripts/
  build.mjs          이어붙이기 빌드 + 개발 서버
  simplify-geo.py    원본 GeoJSON → src/data/geo.js
dist/
  index.html         Artifact 에 올리는 산출물 (커밋함)
  preview.html       로컬에서 열어보는 완전한 HTML
docs/
  DATA_POLICY.md     데이터 보존 원칙 — 코드를 고치기 전에 읽을 것
  ARCHITECTURE.md    데이터 모델과 확장 방법
```

### 왜 번들러가 없는가

Artifact 로 게시하면 외부 스크립트를 불러올 수 없어 결과물이 어차피 한 파일이어야 합니다. 순서대로 이어 붙이면 끝나는 일이라 도구를 늘리지 않았습니다. 모듈이 아니라 **전역 스코프를 공유**하므로, `scripts/build.mjs` 의 `SCRIPTS` 배열 순서가 곧 의존 순서입니다.

---

## 배포

`dist/index.html` 을 Artifact 에 게시합니다. 규칙이 하나 있습니다.

> **항상 같은 Artifact 를 갱신할 것.** 새 Artifact 로 게시하면 새 빈 저장소가 만들어지고, 그동안 쌓은 답사 기록에 접근할 수 없게 됩니다.

Claude 대화에서 기존 아티팩트 URL을 알려주고 `dist/index.html` 을 게시하면 같은 링크가 갱신됩니다. 자세한 이유는 [docs/DATA_POLICY.md](docs/DATA_POLICY.md).

로컬(`npm run dev`)에서는 계정 저장소를 쓸 수 없으므로 IndexedDB 로 자동 대체됩니다. 즉 **개발용 데이터와 실제 답사 데이터는 서로 섞이지 않습니다.**

## 기능

**지도** · 외부 타일 없이 동작하는 전국 지도. 팬·핀치줌, 시군구 경계 자동 노출, 축척바. 좌표를 찍으면 시·도와 시·군·구를 자동 판별합니다. 시장아파트 / 현재역 / 과거역(1970–80s) / 철도 노선 / 터미널 / 시장 레이어를 각각 켜고 끄고, 반경 500m·1km·2km 를 겹쳐 봅니다.

**프로젝트** · 기본 23개 항목과 사용자가 직접 만드는 항목(7가지 형식). 엑셀형 표에서 정렬·필터·검색·다중 선택.

**답사 기록** · 사진 다중 업로드(자동 압축·썸네일·선명도 측정), 카테고리·촬영일·입면 방향·태그. 분류별 연구 노트.

**입면** · 같은 면 사진을 방향별로 묶고 선명도순으로 추천 → 네 모서리 지정 → 호모그래피로 원근 보정 → 기울기·대비·흑백·선 추출 → 프로젝트 저장 / PNG / 선 데이터(SVG·DXF).
사진을 도면으로 자동 변환하지 않습니다. **트레이싱 베이스 이미지**를 만드는 것이 목적입니다.

**분석** · 지역 분포(대도시 / 그 외 구분), 결합 유형, 건축 연대, 교통시설 거리 중앙값과 반경별 집계, 현재역−과거역 거리 차, 규칙 기반 유형 가설, 기록된 데이터만 근거로 답하는 AI 질의.

**출력** · 답사 보고서와 16:9 발표 슬라이드(인쇄 → PDF), CSV, 사진 원본까지 포함한 JSON 백업.

## 자주 하는 작업

**항목 추가** — 앱 안에서: 설정 → 사용자 정의 항목. 코드 수정 불필요.
**기본 항목 추가** — `src/core.js` 의 `BASE_FIELDS` 에 `{k, label, type}` 추가. 표에도 넣으려면 `src/projects.js` 의 `TABLE_COLS` 에 키를 추가합니다. 기존 프로젝트에는 빈 값으로 나타나며 데이터는 그대로입니다.
**저장 구조 변경** — `SCHEMA_VERSION` 을 올리고 `MIGRATIONS` 에 항목을 추가합니다. 규칙은 [docs/DATA_POLICY.md](docs/DATA_POLICY.md).
**참조 지점(역·터미널) 일괄 입력** — 지금은 앱에서 하나씩 등록합니다. 대량 입력이 필요하면 JSON 백업 파일의 `facilities` 배열에 넣고 복원하는 방법이 가장 빠릅니다.
